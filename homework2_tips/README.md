# Домашнее задание 2. Исследовательский анализ данных (Python)

Анализ энергопотребления сталелитейного предприятия (35 040 измерений с шагом 15 минут, 2018 год).

## Содержание
1. Временной диапазон данных
2. Описательная статистика
3. Статистика по сезонам
4. Уровни загрузки (33-й и 67-й процентили)
5. Метод главных компонент (PCA)
6. Кластеризация k-средних
7. Спектр временного ряда (FFT)

## Структура
- `2_homework_eda_feature_engineering.ipynb` — решённый блокнот (все самопроверки ✅)
- `data/Сталелитейные_данные.csv` — исходные данные
- `requirements.txt` — зависимости

## Запуск
```bash
pip install -r requirements.txt
jupyter notebook 2_homework_eda_feature_engineering.ipynb
```
